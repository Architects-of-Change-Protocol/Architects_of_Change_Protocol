## 5. Publication approval gate

Publication (even of a prerelease) is blocked until **all** of the following are explicitly
resolved by the founder / release authority, in writing:

1. **Scope ownership verified** — confirm control of the `@aoc` npm scope (or choose GitHub
   Packages / another registry per `PACKAGE_DISTRIBUTION_STRATEGY.md`).
2. **Registry chosen** — and consumer-side install instructions confirmed for that choice.
3. **Prerelease tag chosen** — `rc` or `next`, recorded in `PRERELEASE_POLICY.md`.
4. **Version cut via Changesets** — `changeset pre enter <tag>` + `changeset version` on a release
   branch; changelog generated; version graph re-validated.
5. **`private: true` flipped** — a deliberate, reviewed commit, together with any `publishConfig`
   the chosen registry requires.
6. **Credentials provisioned outside the repository** — with 2FA/OIDC; never committed.
7. **Provenance enabled** — publish from CI with `--provenance` where the registry supports it.
8. **Final evidence regenerated** — `npm run protocol:release:manifest` on the exact release
   commit; checksums recorded in `docs/release/evidence/` and shared with consumers.
9. **Rollback path acknowledged** — per `PRERELEASE_POLICY.md`: artifacts immutable, versions never
   reused, consumer rollback is pin-based.

Until this gate is passed, the supported distribution mechanism remains the checksummed internal
tarball (`npm run protocol:pack`), exactly as consumed by AOC Enterprise today.
